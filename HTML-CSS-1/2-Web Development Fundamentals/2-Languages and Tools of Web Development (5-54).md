## เนื้อหา (เรียงตามลำดับ)

### 1) 3 บทบาทของนักพัฒนาเว็บ
- **Front-end** — ส่วนที่ผู้ใช้เห็นและโต้ตอบด้วย (สิ่งที่ Aum กำลังฝึกอยู่)
- **Back-end** — ฝั่ง server/database ที่อยู่เบื้องหลัง
- **Full-stack** — ทำได้ทั้งสองฝั่ง

### 2) 3 ภาษาหลักของเว็บ (นี่คือหัวใจของคลิป)
| ภาษา | ชื่อเต็ม | ประเภท |
|---|---|---|
| **HTML** | Hypertext Markup Language | Markup Language (โครงสร้างหน้าเว็บ) |
| **CSS** | Cascading Stylesheet | Styling Language (ตกแต่งหน้าตา) |
| **JavaScript** | — | Programming Language (พฤติกรรม/logic) |

### 3) Learning Path (roadmap ที่ Mosh แนะนำ)
แนะนำให้ **ใช้เวลา 3-5 ชม./วัน ในการเรียน/เขียนโค้ด** แล้ววาง timeline ไว้ประมาณนี้:

```
TODAY -------- 6 สัปดาห์ -------- 3 เดือน -------- 5 เดือน
HTML+CSS       JavaScript          React            Git
```

พร้อมโชว์ทางเลือกของ JS Framework ที่นิยม 3 ตัว: **React, Angular, Vue** (ยังไม่ได้บอกว่าต้องเลือกตัวไหน แค่แนะนำให้รู้จักไว้)

### 4) Version Control Systems
สไลด์หัวข้อ **"Version Control Systems"** แนะนำ 3 ตัว:
- **Git** ← ตัวหลักที่จะใช้ (มีข้อความบอกว่า "Used in 70% of software development teams")
- Subversion (SVN)
- Mercurial

ประโยชน์ของ Version Control: **"Track our project history"** (ดูประวัติการแก้โค้ดย้อนหลัง) และ **"Work collaboratively with others"** (ทำงานร่วมกับคนอื่นได้)

### 5) ปิดท้ายด้วยการเปลี่ยนหัวข้อ
คลิปจบด้วยข้อความ **"How the web works"** ซึ่งเป็นหัวข้อของคลิปถัดไป (เว็บทำงานยังไง — เชื่อมกับ "Key concepts: URL, HTTP, DOM" ที่พูดถึงในคลิป intro ก่อนหน้า)

## สรุปที่ใช้ได้จริง

คลิปนี้เป็นคลิป **overview ก่อนเริ่มลงมือจริง** ไม่มีโค้ดให้พิมพ์ตาม แต่มี 2 อย่างที่ Aum ควรจำไว้:

1. **Roadmap ของ Mosh**: HTML+CSS → JS (6 สัปดาห์) → Framework อย่าง React (3 เดือน) → Git (5 เดือน) — ลำดับนี้ต่างจาก stack ที่ Aum ใช้ทำงานจริงอยู่แล้ว (React มาก่อน Git ในคอร์สนี้ แต่ในทางปฏิบัติ Aum ใช้ Git คู่กับ React ตั้งแต่แรกอยู่แล้วในงาน จึงไม่ต้องกังวลว่าต้องเรียงตามนี้เป๊ะ)
2. **Git = version control หลักที่ต้องรู้** — ใช้ track ประวัติโค้ดและทำงานร่วมกับทีม ตรงกับที่ Aum ใช้อยู่แล้วในงานจริง (Firmware Airflow Dashboard project)
